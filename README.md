# diagnostic

A collection of Dart/Flutter packages that provide a unified diagnostic interface and Flutter-specific integrations.

Packages

- packages/diagnostic — Core, platform-agnostic diagnostic interfaces and manager.
- packages/flutter_diagnostic — Flutter integrations and helpers built on top of the core package.
